## 🇨🇳 中文介绍

### 概述

轻量级科学计算器，单 HTML 文件，开箱即用。采用玻璃态（Glassmorphism）UI 设计，交互流畅，无需安装任何依赖。

### 功能

| 类别 | 功能 |
|------|------|
| **基础运算** | `+ − × ÷`、`%`、`±`、括号、退格、清除 |
| **科学函数** | `sin / cos / tan`（DEG/RAD 切换）、`sinh / cosh / tanh` |
| **对数/指数** | `log / ln / log₂`、`10ˣ`、`exp` |
| **高级运算** | `√ x² xʸ x! 1/x \|x\|` |
| **常量** | `π`、`e` |
| **主题** | 暗色/亮色模式一键切换（持久化） |
| **历史记录** | 侧滑面板，localStorage 存储，点击回填 |
| **键盘支持** | 数字键、运算符、Enter 计算、Backspace/ESC |
| **交互反馈** | 按钮涟漪动画、结果弹出动画 |
| **自适应** | 桌面、平板、手机全适配 |

### 快速开始

1. 直接用浏览器打开 `index.html`
2. 或用 HTTP 服务器托管：
   ```bash
   cd scientific-calculator
   python3 -m http.server 8080
   ```
   然后访问 `http://localhost:8080`

### 技术栈

纯 **HTML5 + CSS3 + Vanilla JavaScript**，零依赖。

## 🇬🇧 English

### Overview

A lightweight scientific calculator in a single HTML file. Zero dependencies, just open and use. Features a modern glassmorphism UI with smooth animations.

### Features

| Category | Functions |
|----------|-----------|
| **Basic** | `+ − × ÷`, `%`, `±`, parentheses, backspace, clear |
| **Trigonometry** | `sin / cos / tan` (DEG/RAD toggle), `sinh / cosh / tanh` |
| **Log/Exp** | `log / ln / log₂`, `10ˣ`, `exp` |
| **Advanced** | `√ x² xʸ x! 1/x \|x\|` |
| **Constants** | `π`, `e` |
| **Theme** | Dark/Light mode toggle (persisted) |
| **History** | Slide-out panel, localStorage, click to restore |
| **Keyboard** | Digits, operators, Enter to calculate, Backspace/ESC |
| **Animations** | Ripple effect, result pop animation, smooth transitions |
| **Responsive** | Desktop, tablet, mobile |

### Quick Start

1. Open `index.html` directly in any browser
2. Or serve via HTTP:
   ```bash
   cd scientific-calculator
   python3 -m http.server 8080
   ```
   Then visit `http://localhost:8080`

### Tech Stack

Pure **HTML5 + CSS3 + Vanilla JavaScript**, no frameworks, no dependencies.
